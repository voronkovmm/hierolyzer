# Hierolyzer

Unity editor tool for keeping scene hierarchies readable and healthy.

## Installation

Unity Package Manager → `Add package from git URL...`:

```
https://github.com/voronkovmm/hierolyzer.git
```

## Features

- [Scene headers](docs/headers.md) - colored section dividers for the Hierarchy window.

More hierarchy health checks (broken references, missing components, etc.) are planned.
